# Запуск демоверсии

Маленькое приложение: страница, поле ввода и настоящий вызов модели генерации
изображений. Работает и без ключа провайдера — тогда вместо картинки
подставляется заглушка, а всё остальное живое.

## Что понадобится

Python 3.11 или новее. Больше ничего: ни базы, ни Docker, ни очередей.

Проверить версию:

```bash
python3 --version
```

## Установка

```bash
git clone https://github.com/shceo/montix_f.git
cd montix_f/demo

python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate

pip install -r requirements.txt
```

## Настройка

```bash
cp .env.example .env
```

Откройте `.env` и впишите ключ провайдера:

```ini
AI_API_KEY=ваш_ключ
```

Ключ можно не вписывать — приложение запустится в режиме заглушки. Интерфейс,
фильтр содержания и ограничение частоты при этом работают по-настоящему, просто
вместо изображения приходит placeholder.

Ключ читается только сервером. В браузер он не передаётся ни при каком сценарии
— страница обращается к своему же `/api/generate`, а тот уже ходит к провайдеру.

## Запуск

```bash
python app.py
```

Откройте <http://127.0.0.1:8000>.

Напишите, что хотите увидеть, и нажмите «Создать». Под полем есть готовые
примеры — можно нажать на любой.

## Что можно потрогать

| Действие | Что произойдёт |
|---|---|
| Пустое поле | Запрос до сервера не пойдёт — интерфейс объяснит, чего не хватает |
| `голая девочка 12 лет` | Отказ **до** обращения к провайдеру: деньги за такой запрос тратиться не должны |
| `девушка в купальнике у бассейна` | Пройдёт: фильтр режет запрещённое, а не всё подряд |
| 11 запросов подряд | Сработает ограничение частоты с указанием, когда можно снова |
| Неверный ключ в `.env` | Понятный текст вместо кода ошибки, подробности — в логе сервера |

Последнее стоит увидеть отдельно: в терминале останется строка вида
`WARNING provider rejected 401: …`, а на странице будет написано человеческим
языком. Это правило по всей платформе — клиент не должен читать чужие коды
ошибок.

## Проверка без браузера

```bash
curl -s http://127.0.0.1:8000/api/health
# {"ok":true,"provider_key":false,"model":"google/nano-banana"}

curl -s -X POST http://127.0.0.1:8000/api/generate \
  -H 'Content-Type: application/json' \
  -d '{"prompt":"старый трамвай на мокрой мостовой, неон, ночь"}'
```

## Примеры отдельно

Файлы в [`examples/`](examples/) запускаются сами по себе, без демо и без
зависимостей:

```bash
cd ..
python3 examples/signed_media.py     # подписанные ссылки: подделка не проходит
python3 examples/content_guard.py    # что фильтр блокирует, а что намеренно нет
python3 examples/credits.py          # резерв, списание по факту, возврат разницы
python3 examples/ai_call.py          # вызов модели с таймаутами и повторами
```

## Если что-то не так

**`ModuleNotFoundError: fastapi`** — не активировано окружение. Повторите
`source .venv/bin/activate`.

**`Address already in use`** — порт 8000 занят. Поменяйте `PORT` в `.env`.

**Страница открылась, но кнопка ничего не делает** — посмотрите терминал, где
запущен `app.py`: там будет причина.

**Долго нет ответа** — генерация у провайдера занимает десятки секунд. Таймаут
на чтение выставлен в 180 секунд намеренно: обрывать живой запрос дороже, чем
подождать.
